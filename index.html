🚀 CityFix – Intelligent Civic Platform

📲 Easy Reporting

Photo, one-tap geo-location, smart categories (roads, water, electricity, safety, cleanliness). Works on any smartphone.

📍 Real-Time Tracking

Every complaint gets a unique ID (CFX-001, CFX-002...). Citizens track “Pending → In Progress → Resolved” live, no refresh needed.

🧠 Smart Priority

Complaints auto-labeled as Critical / High / Normal based on keywords, ensuring urgent issues get immediate attention.

📊 Admin Dashboard

Centralized analytics, department filtering, live status controls, and complaint management (delete, reset counter).

🔔 Real-Time Sync

When admin updates status, user sees change instantly. No delays, no confusion.

🌙 Accessible Design

Dark/light mode, GPS + manual location, works on any device. Bilingual support (English/Arabic).
