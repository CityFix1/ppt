🚀 What CityFix delivers today

📲 Easy reporting

Users submit complaints with photo, category, description, and location. GPS auto‑detection available.

🆔 Case ID tracking

Every complaint gets a unique ID (CFX-001, CFX-002…). Users can track status anytime.

👑 Admin dashboard

Centralised view of all complaints. Filter by category, status, priority, or search by ID.

⚡ Live status updates

Admin changes status → user page updates automatically without refresh. Real-time transparency.

🏷️ Smart priority

Complaints auto‑labeled as Critical / High / Normal based on keywords.

🌙 Accessible design

Dark/light mode, mobile‑friendly, works on any device with a browser.
